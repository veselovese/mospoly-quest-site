# Таймер смены — задача A30

У смены есть лимит времени: **Московский зоопарк — 40 минут, Орлов — 30 минут**. По комментарию руководителя
время прохождения хранится на бэке, а фронтенд показывает обратный отсчёт и завершает смену, когда время вышло.

Бэкенд на момент написания не обновлён, поэтому ниже — **предлагаемый контракт**. Фронтенд переживает отсутствие
новых полей (см. «Запасные значения»), поэтому его можно выкатывать раньше бэкенда.

## Контракт API

- **Лимит у квеста.** В публичной конфигурации квеста (`quest` в `GET /api/events/{code}/` и в ответе регистрации)
  есть `time_limit_seconds`: `2400` для `zoo`, `1800` для `orlov`. Меняется в админке.
- **Дедлайн у участника.** `POST /api/participants/` дополнительно возвращает:
  - `deadline_at` — конец смены (`started_at` + лимит квеста), ISO-время;
  - `server_time` — текущее время сервера, по нему фронтенд поправляет часы устройства.
- **После дедлайна.** `POST /api/tasks/{id}/attempts/` отвечает `409`:
  `{"detail": "Время смены истекло.", "code": "time_expired"}`.
- **Завершение по времени.** `POST /api/participants/finish/` принимает `{"reason": "timeout"}` и после дедлайна,
  `finish_reason` в ответе — `timeout`. `time_seconds` в итогах и рейтинге не больше лимита.

## Запасные значения на фронтенде

- Нет `time_limit_seconds` → лимит из `src/quest/questRegistry.js` (`fallbackConfig.time_limit_seconds`: 40 и 30 минут).
- Нет `deadline_at` → дедлайн = `started_at` + лимит.
- Нет `server_time` → поправка часов 0.
- Сервер отвечает `400` на `reason: "timeout"` → завершение повторяется с `gave_up`, а на экране итогов
  всё равно показывается «Время смены вышло».

## Поведение

- Отсчёт «Осталось мм:сс» — в верхней части боковой панели (`src/components/QuestTimer.jsx`).
  На узких экранах — в компактной верхней полосе между брендом и меню, без подписи.
- 5 минут и меньше — жёлтый, 1 минута и меньше — красный с пульсацией (без неё при `prefers-reduced-motion`).
  Экранные читалки слышат «Осталось меньше 5 минут» и «Осталось меньше минуты».
- Время считается от часов на каждом тике и при возвращении на вкладку, поэтому в фоне не отстаёт.
- Когда время вышло, `finish('timeout')` вызывается один раз. Пока результат сохраняется, задания закрыты
  оверлеем «Время смены вышло · Сохраняем результат…». При ошибке — сообщение и «Повторить».
  Если сервер не знает токен (`401`), повтор не поможет: смена сбрасывается на экран входа с пояснением.
- Если страницу открыли уже после дедлайна, смена завершается сразу.
- Ответ `409 time_expired` на попытку (часы устройства отстают) тоже завершает смену.
- Экран итогов: надзаголовок «Время смены вышло», концовка — по числу решённых заданий, как при досрочном завершении.
- Экран входа: в подвале «лимит 40 минут».
